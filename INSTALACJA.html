Instrukcja instalacji na Androidzie — krok po kroku
📱 Instalacja w 30 sekund

Otwórz plik index.html przez lokalny serwer lub hosting — Chrome zapyta automatycznie o instalację

✅ NAJŁATWIEJSZA METODA

Metoda 1 — Hosting na Google Drive / GitHub Pages

Wgraj pliki na darmowy hosting — otwórz link na telefonie — zainstaluj. Działa zawsze.

1
Wgraj folder elewacja-pwa na GitHub Pages
Utwórz repozytorium na github.com → wgraj wszystkie pliki → Settings → Pages → Deploy from main branch
👉 Darmowe. Adres: twoja-nazwa.github.io/elewacja-pwa/
2
Otwórz link w Chrome na Androidzie
Wpisz adres lub zeskanuj QR kod
3
Kliknij "Zainstaluj aplikację" w Chrome
Chrome wyświetli baner na dole ekranu lub opcję w menu (⋮) → "Dodaj do ekranu głównego"
📲 METODA LOKALNA (bez internetu)

Metoda 2 — Lokalny serwer HTTP na Androidzie

Nie wymaga internetu ani komputera. Serwer działa z telefonu.

1
Zainstaluj "Simple HTTP Server" z Google Play
Aplikacja: "Simple HTTP Server" (pnig.de) — darmowa, 3 MB
Alternatywa: "kWS - Android Web Server" lub "HFS HTTP File Server"
2
Skopiuj folder elewacja-pwa na telefon
Podłącz telefon USB do komputera → przeciągnij folder do Pobrane/ lub Documents/
3
W Simple HTTP Server wskaż folder i wystartuj
Wybierz katalog z plikami → kliknij Start → serwer działa na localhost:8080
4
Otwórz Chrome: http://localhost:8080/index.html
Chrome wykryje PWA i zaproponuje instalację
5
Zainstaluj → gotowe!
Po instalacji aplikacja działa offline bez serwera — dane zapisane lokalnie (IndexedDB)
💻 METODA Z KOMPUTEREM

Metoda 3 — Lokalny serwer z komputera (sieć WiFi)

1
Uruchom serwer z folderu elewacja-pwa
W terminalu/wierszu poleceń w folderze z plikami:
python -m http.server 8080
lub Node.js:
npx serve .
2
Sprawdź IP komputera w sieci WiFi
Windows: ipconfig → IPv4 np. 192.168.1.100
Mac/Linux: ifconfig | grep inet
3
Na telefonie otwórz Chrome z adresem komputera
Telefon i komputer muszą być w tej samej sieci WiFi
http://192.168.1.100:8080/index.html
4
Menu Chrome (⋮) → Zainstaluj aplikację
Lub kliknij baner który pojawi się automatycznie
HTTPS wymagane dla pełnego PWA. Dla localhost działa bez HTTPS. Dla IP w sieci — Chrome może ostrzegać, kliknij "Kontynuuj mimo to".
